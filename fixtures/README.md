# Fixtures

Deterministic inputs and captured ground truth for the encoder tests (SPEC.md 8.2).

## `pages/`

Generated by `scripts/gen-fixtures.py` (Python standard library only, no dependencies).
Geometry is placed on the 600 dpi device grid (1 px = 0.12 pt) so 1 px rules and checkerboard
cells land on whole raster pixels. `unicode-text-*.pdf` is produced from `unicode-text.txt`
by Apple's text filter (`cupsfilter -m application/pdf`) so it carries real Cyrillic/Greek
glyphs; it is therefore only reproducible on macOS.

| page | what it exercises |
|---|---|
| blank | minimal job: PJL envelope, page header, end records |
| black-square | one solid 50 mm square: band boundaries inside solid black |
| horizontal-lines, vertical-lines | 1–8 px rules, 0.25–2 pt strokes, gratings with 1–4 px gaps, diagonals |
| checkerboard | 1–64 px cells: JBIG behaviour on worst-case and best-case patterns |
| gray-ramp | 16 and 256 steps, continuous wedge, tone patches: halftoning |
| small-text | 4–12 pt serif/sans, reversed text, Latin-1, an 8 pt paragraph |
| unicode-text | non-Latin glyphs through the text filter |
| photo | procedural 1000×750 gray image at 200 ppi: photographic halftoning |
| test-sheet | the quality-program composite (SPEC.md 7.2), without QR/barcode for now |

## `oracle/samsung/`

Captured by `scripts/capture-vendor-output.sh` from the vendor driver (Samsung UPD 3.93.00,
Intel binary under Rosetta 2) on macOS 26.6.2, 2026-09-02. Do not regenerate casually: the
vendor filter will stop running on macOS 28.

- `<name>.spl` — the vendor's native SPL/QPDL job. Golden reference.
- `<name>.ras.gz` — the CUPS raster (v3, uncompressed, 8-bit K, 600 dpi) that the vendor
  filter consumed to produce it. Our pipeline is tested on exactly this input.
- `<name>.opts` — the option string passed to both `cupsfilter` and the vendor filter.
- `CAPTURE-INFO.md` — tool versions, hashes, raster header summary and SHA-256 per file.
- `Samsung_M2020_Series.ppd`, `lpoptions*.txt`, `ipp-printer-attributes.txt`,
  `vendor-sha256.txt` — the queue as it was configured.
- `filter-stderr.example.log` — what the vendor filter reports on stderr, including the full
  list of `printer-state-reasons` it knows about (useful for M9).

Known non-determinism: the first PJL line carries `SERVICEDATE=<yyyymmdd>`, so a recapture on
another day differs in those 8 bytes only (verified by re-running on the same day: identical).

Variants on `small-text-a4`: `.best` (1200 dpi), `.tonersave`, `.manualfeed`, `.edge-off`,
`.edge-max`, `.copies2`, `.duplex-long`; `blank-a4.skipblank`. The manual-duplex variant needs
`/Library/Caches/com.sec.printer` to exist (the script creates it), otherwise the vendor filter
segfaults on a NULL `FILE*`.

`media/<PageSize>.spl` is a sweep over all 14 PPD paper sizes with a 30 mm square, used to
derive the band-width rule and the paper codes (see `docs/spl-qpdl.md`).

## `oracle/splix/`

Reserved for SpliX output of the same pages (M5), produced by a separately built SpliX and
never linked into the product (ADR-010).
